# BuildFerry

BuildFerry is a proposed self-hosted dashboard and scheduler for distributing CI work across connected GitHub accounts and runner providers.

The MVP will support GitHub App onboarding, account allowance tracking, configurable fallback priorities, Ubicloud runners, and parallel test execution. Project checks and release approvals remain controlled by each source repository.

Start with the [MVP plan](docs/mvp-plan.md), which defines the setup experience, scheduling rules, security boundaries, rollout, and acceptance criteria.

Status: planning. There is no runnable application or installer yet.
